页面右上角的工具栏从左到右依次是：当前模型服务商、GitHub 仓库链接、主题切换、界面语言切换和**设置**（齿轮图标）。

![模型与 API 设置](https://raw.githubusercontent.com/cokice/japanese-analyzer/master/docs/images/provider-settings.png)

## 模型与 API

点击齿轮图标打开**设置**。**模型与 API** 分组包含以下选项：

| 选项 | 说明 |
| --- | --- |
| 模型服务 | 在 **Gemini** 和 **DeepSeek** 之间切换。默认是 DeepSeek。 |
| 模型版本 | DeepSeek 为 `deepseek-flash`。Gemini 可选 `gemini-flash-latest` 或 `gemini-flash-lite-latest`。 |
| API 密钥（可选） | 为当前服务商填写你自己的 Key。留空则使用服务器配置的 Key。 |

修改后点击**保存设置**。页面提示「设置已保存」后生效。当前服务商会显示在工具栏最左侧。

所选的模型服务和版本会用于句子解析、翻译、单词详解、图片识别和 AI 日语助手。

<Info>
  Gemini 和 DeepSeek 的 Key 分开保存。切换服务商时，输入框会显示对应服务商的 Key。
</Info>

### 自己的 Key 如何使用

- Key 保存在当前浏览器的本地存储中，不会同步到其他设备。
- 调用模型时，Key 随请求发送到应用服务端，由服务端转发给模型服务商。服务端不保存它。
- 你填写了 Key 时，优先使用你的 Key；留空时使用服务器配置的 Key。

<Warning>
  不要在公共或共享电脑上保存个人 API Key。用完后清空输入框并保存，即可删除本地保存的 Key。
</Warning>

## 输出方式

| 选项 | 说明 |
| --- | --- |
| 流式输出 | 默认开启。实时显示解析、翻译和释义。网络不稳定时可以关闭，改为一次性返回完整结果。 |
| 深度思考 | 选择 DeepSeek 时显示，目前暂不可用。 |

## 界面语言

点击工具栏中的语言按钮，可以选择：

- 简体中文（默认）
- 繁體中文
- English
- 한국어

界面文字、整句译文、单词释义和 AI 日语助手的回答都会一起切换到所选语言。繁體中文使用台湾惯用词汇，而不是简单的简繁转换。日语原文、读音、日语例句和日语词性标签始终保持日语。

## 主题

点击工具栏中的主题按钮，可以在以下模式间切换：

- **亮色模式**
- **暗色模式**
- **跟随系统**

## 设置保存在哪里

以下设置都保存在当前浏览器的本地存储中，清除浏览器数据后会恢复默认值：

- 模型服务、模型版本和各服务商的 API Key
- 流式输出开关
- 界面语言和主题
- 朗读的语音引擎、声音、语速和风格
- 最近解析记录和当天的今日一句
