你可以让应用朗读输入框中的日语原文，或在单词详情中朗读单个词的发音。

## 朗读原文

点击输入区的**朗读**按钮。鼠标悬停时，按钮会显示预计耗时，例如「朗读文本（约 5-10秒）」。

| 原文长度 | 预计耗时 |
| --- | --- |
| 20 字以内 | 5–10 秒 |
| 21–50 字 | 10–20 秒 |
| 51–100 字 | 20–30 秒 |
| 超过 100 字 | 30–60 秒 |

在单词详情面板中，点击**朗读发音**可以只朗读所选的词。

## 选择语音引擎

打开输入区的**语音设置**，在**语音引擎**中选择：

<Tabs>
  <Tab title="Edge TTS（默认）">
    无需任何 API Key，开箱即用。

    | 设置 | 选项 |
    | --- | --- |
    | 语音性别 | **女声 (Nanami)**：`ja-JP-NanamiNeural`<br />**男声**：`ja-JP-KeitaNeural` |
    | 语速 | 从 -100 到 +100，步长 10。界面按数值显示为很慢、慢、正常、快、很快。 |
  </Tab>
  <Tab title="Gemini TTS">
    使用 `gemini-3.1-flash-tts-preview` 模型，需要 Gemini API Key。服务器配置了 `GEMINI_API_KEY`，或你在**设置**中填写了 Gemini Key，都可以使用。

    | 语音 | 风格 |
    | --- | --- |
    | Kore | 坚定 |
    | Puck | 乐观 |
    | Zephyr | 明亮 |
    | Aoede | 轻松 |
    | Leda | 年轻 |
    | Charon | 信息性 |

    **语音风格**可选：

    - **自然朗读**：默认风格。
    - **慢速朗读**：放慢语速，适合跟读。
    - **清晰朗读**：发音更清楚。
  </Tab>
</Tabs>

你的语音引擎、声音、语速和风格会保存在当前浏览器中，下次打开时自动恢复。

## 朗读失败时

| 提示 | 处理 |
| --- | --- |
| 请先输入文本 | 输入框为空。先输入要朗读的日语。 |
| 未提供 API 密钥 | 使用 Gemini TTS 但没有可用的 Gemini Key。填写 Key，或切换回 Edge TTS。 |
| 上游 TTS 请求超时，请稍后重试。 | 语音服务 60 秒内没有响应。缩短原文后重试。 |
| Edge TTS 请求失败（HTTP 状态码） | Edge TTS 语音接口返回了错误。稍后重试，或切换到 Gemini TTS。 |
| Edge TTS 返回空音频 | 语音服务没有返回音频。稍后重试，或切换到 Gemini TTS。 |

<Note>
  Edge TTS 请求会经应用服务端转发到项目作者提供的语音接口 `api.howen.ink`。如果你不希望原文发送给该服务，请改用 Gemini TTS。详见[密钥与隐私](/privacy)。
</Note>
