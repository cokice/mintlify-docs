首页有两个帮助你快速开始的区域：**今日一句**和**最近**。点击其中任意一项，应用会直接填入原文并开始解析。

## 今日一句

今日一句是每天推荐的一个日语短句，附带假名注音和当前界面语言的译文。点击它即可解析这句话。

### 句子如何生成

- 句子按**日本时间**零点更新，全天所有访客看到同一句。
- 服务端每天用 AI 生成一次，并缓存结果。同一天内的后续请求不会再调用模型。
- 主题和语法点按日期轮换。19 个主题和 17 个语法点组合，要 323 天才会重复。
- 难度为 JLPT N5～N3，长度 10～28 个字符，内容避开人名、品牌、政治、宗教、灾难等话题。
- 同时生成简体中文、繁體中文、English 和 한국어 四种译文。
- 生成后会校验格式，并确认分词能拼回原句。不合格时会换一句重试。

### 备用句

以下情况下，首页会改为显示内置的备用句：

- 服务器没有配置 `DEEPSEEK_API_KEY` 或 `GEMINI_API_KEY`。
- 生成失败，或服务端访问不到模型服务商。
- 请求超时。

备用句共 7 句，已预先分词和注音，按日期轮换，不调用 AI。

<Note>
  今日一句只使用服务器配置的 Key 生成，不会使用访客在**设置**中填写的 Key。服务端优先使用 DeepSeek，没有 DeepSeek Key 时改用 Gemini。
</Note>

<Tip>
  如果首页一直只在几句固定的句子中轮换，说明服务器没有可用的 Key，或出站网络无法访问模型服务商。详见[常见问题](/troubleshooting)。
</Tip>

## 最近

每次成功解析后，应用会把原文保存到**最近**列表。

- 记录只保存在当前浏览器的本地存储中，不会上传到服务器。
- 最多保存 50 条。相同的原文只保留最新一次。
- 首页默认显示最近 3 条。点击**显示全部 N 条**查看全部记录。
- 点击**清空历史记录**可以删除所有记录。

<Warning>
  在无痕模式或禁用了本地存储的浏览器中，页面会提示「历史记录暂时无法保存到浏览器，刷新后可能丢失。」
</Warning>
