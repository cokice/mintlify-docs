句子解析是应用的核心功能。你输入一段日语后，应用会把它拆成词项，为每个词标出假名读音、罗马音和词性，再在下方生成整句译文。

## 解析一段日语

<Steps>
  <Step title="输入原文">
    在输入框中输入或粘贴日语。你也可以点击首页的**今日一句**或**最近**记录，直接填入原文。
  </Step>
  <Step title="点击解析">
    点击**解析**。开启流式输出时，词项会边生成边显示。
  </Step>
  <Step title="阅读结果">
    结果区显示逐词注音。译文区在解析完成后自动翻译整段原文。
  </Step>
</Steps>

解析过程中，你可以点击**终止解析**停止当前请求。解析完成后，点击**编辑原文**修改句子，或点击**新句子**清空并重新开始。

## 解析结果包含什么

每个词项包含三类信息：

| 信息 | 说明 |
| --- | --- |
| 假名 | 显示在含汉字的词上方。纯假名的词不重复注音。 |
| 罗马音 | 在本地由假名转换，使用平文式拼写，长音保留元音拼写（如 `ou`）。 |
| 词性 | 每个词下方有彩色下划线，颜色对应词性分组。 |

结果下方的图例会列出本句出现的词性分组：名词、动词、形容词、形容动词、副词、连体词、接续词、感动词、助词、助动词和其他。标点符号不显示下划线。

### 显示或隐藏注音

结果区顶部有两个开关：

- **显示假名**：切换汉字上方的假名。
- **显示罗马音**：切换词下方的罗马音。

关闭注音后，你可以用原文自测阅读，再随时打开核对。

## 整句译文

解析完成后，应用会自动把整段原文翻译成当前界面语言。译文区提供以下操作：

- **复制**：复制译文。
- **重新翻译**：对同一原文重新生成译文。
- **收起** / **展开**：折叠或展开译文区。

<Note>
  译文语言跟随界面语言。切换到 English 后，译文、单词释义和 AI 助手的回答都会改用英文。详见[设置](/features/settings#界面语言)。
</Note>

## 长文分段解析

长段落会被自动拆成多段，每段约 280 个字符，最长不超过 420 个字符。应用在句号、问号、感叹号等句末位置断开，并避免拆开成对的括号和引号。

- 开启流式输出时，最多 3 段同时请求；关闭时逐段依次解析。结果都按原文顺序拼接。
- 如果某一段没有返回完整结果，错误信息会指出是第几段，例如「第 2/5 段没有返回完整解析结果，请重试。」
- 应用会校验每段的词项能否拼回原文，拼不回时提示重试，避免出现漏字或多字。

## 粘贴网页和 Markdown

从网页或 Markdown 文档中复制文本时，应用会自动清理格式：

- 去掉 HTML 标签、脚本、样式和隐藏元素，保留段落和换行。
- 去掉 Markdown 的标记符号，保留图片的替代文本。
- 去掉链接地址，只保留链接文字。

<Tip>
  如果你直接输入含 `https://` 链接的文本，应用会把链接作为一个整体保留为符号，不会让模型拆分或注音。
</Tip>

## 流式输出

**流式输出**默认开启，解析、翻译和释义会实时显示。如果网络不稳定、结果经常中断，你可以在**设置**中关闭它，改为一次性返回完整结果。

## 解析失败时

| 提示 | 原因与处理 |
| --- | --- |
| 未提供 API 密钥 | 服务器和浏览器都没有可用的 Key。在**设置**中填写 Key，或让管理员配置服务器 Key。 |
| 被上游模型截断（`finish_reason: length`） | 输出过长。缩短原文后重新解析。 |
| 被上游内容安全策略中止 | 模型服务商拒绝了该内容。 |
| 解析结果未能完整还原原文 | 模型返回的词项与原文不一致。点击重新解析。 |
| 上游接口请求超时，请稍后重试。 | 服务端等待模型服务商 60 秒没有响应。稍后重试。 |
| 上游流式响应空闲超时，请重试。 | 流式输出超过 90 秒没有新内容。重试，或在**设置**中关闭**流式输出**。 |

<Note>
  报错提示会以当前界面语言显示。模型服务商返回的原始错误信息（例如 `HTTP 429: upstream quota exceeded`）会保留原文，方便你排查。
</Note>
