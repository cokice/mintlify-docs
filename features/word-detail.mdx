解析完成后，结果中的每个词都可以点击。应用会结合整句语境生成词典式释义，只解释这个词在本句中的意思，而不是罗列所有义项。

## 查看单词详解

点击解析结果中带下划线的词，详情面板会显示以下内容：

| 字段 | 说明 |
| --- | --- |
| 读音与罗马音 | 所选词的假名和罗马音。模型发现原读音有误时会修正。 |
| 释义 | 本句所用义项的简明释义，通常一到两个近义表达。 |
| 原形 | 词的辞书形。例如「読んだ」的原形是「読む」。 |
| 词性 | 学校文法词性，必要时带细分，例如「動詞（五段・他動）」。 |
| 本句用法 | 这个词与相邻词的搭配，以及在本句中的具体作用。 |
| 词形 | 仅在本句确有活用时显示，例如「読む → 読んだ；た形，表示过去。」 |
| 例句 | 一条使用相同义项或相同活用形的短例句，附带译文。 |

面板中的其他操作：

- **朗读发音**：朗读所选的词。
- **刷新释义**：对同一个词重新生成释义。
- **展开全文** / **收起**：展开或折叠较长的说明。

<Note>
  释义以你当前的界面语言输出。原文超过 1000 个字符时，应用只把所选词前后各两句作为上下文发送，以控制请求长度。
</Note>

## 多词圈选

有些意思要几个词合起来才能讲清楚，例如语法结构「〜なければならない」或惯用语。你可以圈选连续的几个词，让应用把它们当作一个整体讲解。

<Tabs>
  <Tab title="桌面端">
    - 按住鼠标，拖过几个词。
    - 或者先点击一个词，再按住 <kbd>Shift</kbd> 点击另一个词，选中两者之间的所有词。
  </Tab>
  <Tab title="手机端">
    1. 长按一个词约半秒，进入圈选。
    2. 再点击另一个词，选中这一段。
  </Tab>
  <Tab title="从详情面板">
    1. 点击一个词，打开详情面板。
    2. 点击**选中多个词一起解析**。
    3. 再点击另一个词，选中这一段。
  </Tab>
</Tabs>

### 圈选结果

应用会先判断这一段属于哪一类，再给出相应讲解：

| 类型 | 含义 | 示例 |
| --- | --- | --- |
| 一个词 | 本来是一个词，只是被拆开了，例如复合词或专有名词。 | 図書館 |
| 语法结构 | 固定的语法形式，用「〜」表示接续位置。 | 〜なければならない |
| 惯用表达 | 惯用语或固定说法。 | 気がする |
| 词组 | 普通的词组搭配，或只是几个词连在一起。 | 本を読む |

除释义和例句外，圈选结果还会显示**构成**，说明这一段由哪些部分组成、各起什么作用。例如：

```text
なけれ（ない的假定形）＋ば（条件）＋なら（なる的否定接续）＋ない：不这样就不行，即“必须”。
```

### 合并被拆开的词

如果应用判断圈选内容是**一个词**，详情面板会提示「这几个词其实是一个词」，并显示**合并为一个词**按钮。点击后，这几个词项会在当前解析结果中合并为一个，读音也会一并更新。

<Tip>
  合并只影响当前页面中的解析结果。重新解析同一原文时，模型会重新分词。
</Tip>
