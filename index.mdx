日本語文章解析是一款 AI 驱动的日语句子解析 Web 应用。你输入或粘贴一段日语，它会逐词标出假名、罗马音和词性，并在下方给出整句译文。点击任意一个词，你可以查看它在本句中的意思、用法、活用和例句。

<Info>
  想先体验？打开[在线演示](https://nihongodemo.howen.ink/)，无需部署即可开始解析。
</Info>

![解析结果与词典释义](https://raw.githubusercontent.com/cokice/japanese-analyzer/master/docs/images/app-home.png)

### 界面

- 支持简体中文、繁體中文、English 和 한국어。界面、翻译和释义一起切换。
- 支持浅色、深色和跟随系统三种主题。桌面与手机都能使用。
- 长文自动分段解析。粘贴网页或 Markdown 时，自动去掉格式和链接。

## 模型

| 用途 | 默认 | 可选 |
| --- | --- | --- |
| 解析、翻译、释义、AI 助手 | DeepSeek `deepseek-flash` | Gemini `gemini-flash-latest` / `gemini-flash-lite-latest` |
| 图片识别 | 与所选文本模型一致 | — |
| 朗读 | Edge TTS | Gemini TTS（需要 Gemini API Key） |

服务器配置的 API Key 供所有访客使用。使用者也可以在**设置**里填写自己的 Key。该 Key 保存在自己的浏览器中，请求时经应用服务端转发给模型服务商。详见[密钥与隐私](/privacy)。
