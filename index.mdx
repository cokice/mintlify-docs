日本語文章解析是一款面向中文学习者的日语句子解析工具。你可以输入文本或上传图片，快速查看词汇拆解、假名、罗马音、词性、整句翻译和单词详解。

<Info>
  想先体验功能？打开[在线演示](https://nihongodemo.howen.ink/)，无需部署即可开始解析。
</Info>

![日本語文章解析主界面](https://raw.githubusercontent.com/cokice/japanese-analyzer/master/docs/images/app-home.png)

## 你可以做什么

| 功能 | 说明 |
| --- | --- |
| 句子解析 | 查看分词、假名、罗马音、词性标记和中文释义。 |
| 单词详解 | 点击词汇，查看读音、释义、语法角色和上下文解释。 |
| 整句翻译 | 生成中文翻译，快速理解句子语境。 |
| 图片识别 | 上传或粘贴图片，从图片中提取日语文本。此功能需要 Gemini。 |
| 语音朗读 | 使用 Edge TTS 或 Gemini TTS 朗读句子。 |
| AI 日语助手 | 围绕当前句子继续询问语法、词汇和文化背景。 |

## 模型与服务

| 能力 | 默认模型或服务 | 说明 |
| --- | --- | --- |
| 文本解析 | `deepseek-v4-flash` / `deepseek-v4-pro` | 默认使用 DeepSeek。你可以在设置中切换 Flash 或 Pro。 |
| Gemini 文本解析 | `gemini-3.6-flash` / `gemini-3.5-flash-lite` | 你可以在设置中切换 Gemini 模型。 |
| 图片识别 | Gemini | DeepSeek 暂不支持图片识别。 |
| 语音朗读 | Edge TTS / Gemini TTS | 默认使用 Edge TTS。Gemini TTS 需要 Gemini API Key。 |

<Note>
  你可以使用服务器预设的 API Key，也可以在右上角的设置中填写自己的 Key。浏览器设置只保存在本地。
</Note>
