日本語文章解析（中文介面名稱為「日語文章解析」）是一款以 AI 輔助的日語句子解析 Web 應用程式。你輸入或貼上一段日語，它會逐詞標出假名、羅馬拼音和詞性，並在下方提供整句譯文。點選任何一個詞，你就能查看它在這句話中的意思、用法、活用和例句。

<Info>
  想先體驗？開啟[線上展示](https://nihongodemo.howen.ink/)，不必部署就能開始解析。
</Info>

### 介面

- 支援简体中文、繁體中文、English 和 한국어。介面、翻譯和釋義會一起切換。
- 支援淺色、深色和依照系統設定三種主題。電腦與手機都能使用。
- 長文會自動分段解析。貼上網頁或 Markdown 時，會自動移除格式和連結。

## 模型

| 用途 | 預設 | 可選 |
| --- | --- | --- |
| 解析、翻譯、釋義、AI 助手 | DeepSeek `deepseek-flash` | Gemini `gemini-flash-latest` / `gemini-flash-lite-latest` |
| 圖片辨識 | 與所選文字模型相同 | — |
| 朗讀 | Edge TTS | Gemini TTS（需要 Gemini API Key） |

伺服器設定的 API Key 供所有訪客使用。使用者也可以在**設定**中填入自己的 Key。這組 Key 儲存在使用者自己的瀏覽器中，發出請求時會經由應用程式伺服器轉送給模型服務商。詳見[金鑰與隱私](/zh-Hant/privacy)。
