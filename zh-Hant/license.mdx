| 標籤 | 意義 |
| --- | --- |

## 你需要做什麼

<Steps>
  <Step title="散布時提供原始碼">
    散布可執行版本（例如 Docker 映像檔）時，請依 AGPL 第 6 條提供對應原始碼，並保留授權條款和著作權聲明。
  </Step>
  <Step title="提供網路服務時提供原始碼">
    修改本程式後透過網路向他人提供服務時，請依 AGPL 第 13 條，以明顯的方式讓使用者免費取得修改版的對應原始碼。
  </Step>
  <Step title="更新原始碼連結">
    應用程式介面右上角有 GitHub 原始碼連結。部署修改版時，請把它指向你實際執行版本的原始碼，而不是保留無法反映修改內容的上游連結。
  </Step>
</Steps>

<Warning>
  對應原始碼必須與實際執行的版本一致，包括你的修改，以及建置、安裝和執行指令碼。只連結到不含你修改內容的上游儲存庫，並不符合要求。不要把 API Key、密碼等部署憑證放進原始碼套件，提供設定範本即可。
</Warning>
