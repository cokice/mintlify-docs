解析完成後，結果中的每個詞都可以點選。應用程式會配合整句的語境產生辭典式釋義，只說明這個詞在本句中的意思，而不是列出所有義項。

## 查看單字詳解

點選解析結果中有底線的詞，詳細資訊面板會顯示以下內容：

| 欄位 | 說明 |
| --- | --- |
| 讀音與羅馬拼音 | 所選詞的假名和羅馬拼音。模型發現原本的讀音有誤時會加以修正。 |
| 釋義 | 本句所用義項的簡明釋義，通常是一到兩個近義表達。 |
| 原形 | 詞的辭書形。例如「読んだ」的原形是「読む」。 |
| 詞性 | 學校文法的詞性，必要時附上細分，例如「動詞（五段・他動）」。 |
| 本句用法 | 這個詞與相鄰詞的搭配，以及在本句中的具體作用。 |
| 詞形變化 | 只在本句確實有活用時顯示，例如「読む → 読んだ；た形，表示過去。」 |
| 例句 | 一則使用相同義項或相同活用形的短例句，並附上譯文。 |

面板中的其他操作：

- **播放發音**：朗讀所選的詞。
- **重新查詢釋義**：針對同一個詞重新產生釋義。
- **展開全文** / **收合**：展開或收合較長的說明。

<Note>
  釋義會以你目前的介面語言輸出。原文超過 1000 個字元時，應用程式只會把所選詞前後各兩句當作上下文傳送，以控制請求長度。
</Note>

## 多詞圈選

有些意思要幾個詞合起來才講得清楚，例如語法結構「〜なければならない」或慣用語。你可以圈選連續的幾個詞，讓應用程式把它們當成一個整體講解。

<Tabs>
  <Tab title="電腦版">
    - 按住滑鼠，拖過幾個詞。
    - 或者先點選一個詞，再按住 <kbd>Shift</kbd> 點選另一個詞，選取兩者之間的所有詞。
  </Tab>
  <Tab title="手機版">
    1. 長按一個詞約半秒，進入圈選。
    2. 再點選另一個詞，選取這一段。
  </Tab>
  <Tab title="從詳細資訊面板">
    1. 點選一個詞，開啟詳細資訊面板。
    2. 點選**選取多個詞一起解析**。
    3. 再點選另一個詞，選取這一段。
  </Tab>
</Tabs>

### 圈選結果

應用程式會先判斷這一段屬於哪一類，再提供對應的講解：

| 類型 | 意義 | 範例 |
| --- | --- | --- |
| 一個詞 | 本來就是一個詞，只是被拆開了，例如複合詞或專有名詞。 | 図書館 |
| 語法結構 | 固定的語法形式，用「〜」表示接續的位置。 | 〜なければならない |
| 慣用表達 | 慣用語或固定說法。 | 気がする |
| 詞組 | 一般的詞組搭配，或只是幾個詞連在一起。 | 本を読む |

除了釋義和例句，圈選結果還會顯示**構成**，說明這一段由哪些部分組成、各自有什麼作用。例如：

```text
なけれ（ない的假定形）＋ば（條件）＋なら（なる的否定接續）＋ない：不這樣就不行，即「必須」。
```

### 合併被拆開的詞

如果應用程式判斷圈選內容是**一個詞**，詳細資訊面板會提示「這幾個詞其實是一個詞」，並顯示**合併為一個詞**按鈕。點選後，這幾個詞項會在目前的解析結果中合併為一個，讀音也會一併更新。

<Tip>
  合併只會影響目前頁面中的解析結果。重新解析同一段原文時，模型會重新斷詞。
</Tip>
