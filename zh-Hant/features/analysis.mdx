句子解析是應用程式的核心功能。你輸入一段日語後，應用程式會把它拆成詞項，為每個詞標出假名讀音、羅馬拼音和詞性，再在下方產生整句譯文。

## 解析一段日語

<Steps>
  <Step title="輸入原文">
    在輸入框中輸入或貼上日語。你也可以點選首頁的**今日一句**或**最近**紀錄，直接填入原文。
  </Step>
  <Step title="點選解析">
    點選**解析**。開啟串流輸出時，詞項會一邊產生一邊顯示。
  </Step>
  <Step title="閱讀結果">
    結果區會顯示逐詞注音。譯文區會在解析完成後自動翻譯整段原文。
  </Step>
</Steps>

解析過程中，你可以點選**停止解析**來中止目前的請求。解析完成後，點選**編輯原文**修改句子，或點選**新句子**清空並重新開始。

## 解析結果包含什麼

每個詞項包含三類資訊：

| 資訊 | 說明 |
| --- | --- |
| 假名 | 顯示在含漢字的詞上方。純假名的詞不會重複注音。 |
| 羅馬拼音 | 在本機由假名轉換，使用平文式拼寫，長音保留母音拼寫（如 `ou`）。 |
| 詞性 | 每個詞下方有彩色底線，顏色對應詞性分組。 |

結果下方的圖例會列出本句出現的詞性分組：名詞、動詞、形容詞、形容動詞、副詞、連體詞、接續詞、感嘆詞、助詞、助動詞和其他。標點符號不會顯示底線。

### 顯示或隱藏注音

結果區頂端有兩個開關：

- **顯示假名**：切換漢字上方的假名。
- **顯示羅馬拼音**：切換詞下方的羅馬拼音。

關閉注音後，你可以用原文自我測試閱讀能力，再隨時打開核對。

## 整句譯文

解析完成後，應用程式會自動把整段原文翻譯成目前的介面語言。譯文區提供以下操作：

- **複製**：複製譯文。
- **重新翻譯**：針對同一段原文重新產生譯文。
- **收合** / **展開**：收合或展開譯文區。

<Note>
  譯文語言會跟隨介面語言。切換到 English 後，譯文、單字釋義和 AI 助手的回答都會改用英文。詳見[設定](/zh-Hant/features/settings#介面語言)。
</Note>

## 長文分段解析

長段落會自動拆成多段，每段約 280 個字元，最長不超過 420 個字元。應用程式會在句號、問號、驚嘆號等句尾位置斷開，並避免拆開成對的括號和引號。

- 開啟串流輸出時，最多 3 段同時請求；關閉時則逐段依序解析。結果都會依原文順序拼接。
- 如果某一段沒有傳回完整結果，錯誤訊息會指出是第幾段，例如「第 2/5 段未傳回完整解析結果，請再試一次。」
- 應用程式會驗證每段的詞項能否拼回原文，拼不回時會提示重試，避免出現漏字或多字。

## 貼上網頁和 Markdown

從網頁或 Markdown 文件複製文字時，應用程式會自動清理格式：

- 移除 HTML 標籤、指令碼、樣式和隱藏元素，保留段落和換行。
- 移除 Markdown 的標記符號，保留圖片的替代文字。
- 移除連結網址，只保留連結文字。

<Tip>
  如果你直接輸入含有 `https://` 連結的文字，應用程式會把連結整體保留為一個符號，不會讓模型拆分或注音。
</Tip>

## 串流輸出

**串流輸出**預設為開啟，解析、翻譯和釋義會即時顯示。如果網路不穩定、結果經常中斷，你可以在**設定**中關閉它，改為一次傳回完整結果。

## 解析失敗時

| 提示 | 原因與處理方式 |
| --- | --- |
| 未提供 API 金鑰 | 伺服器和瀏覽器都沒有可用的 Key。在**設定**中填入 Key，或請管理員設定伺服器 Key。 |
| 遭上游模型截斷（`finish_reason: length`） | 輸出過長。縮短原文後重新解析。 |
| 遭上游內容安全機制中止 | 模型服務商拒絕了這段內容。 |
| 解析結果未能完整還原原文 | 模型傳回的詞項與原文不一致。請重新解析。 |
| 上游介面請求逾時 | 伺服器端等待上游 60 秒沒有回應，或串流輸出 90 秒沒有新內容。請稍後再試。 |

更多問題請見[常見問題](/zh-Hant/troubleshooting)。
