首頁有兩個幫助你快速開始的區塊：**今日一句**和**最近**。點選其中任一項，應用程式會直接填入原文並開始解析。

## 今日一句

今日一句是每天推薦的一則日語短句，附有假名注音和目前介面語言的譯文。點選它就能解析這句話。

### 句子如何產生

- 句子會在**日本時間**午夜零時更新，全天所有訪客看到的都是同一句。
- 伺服器端每天用 AI 產生一次，並快取結果。同一天內的後續請求不會再呼叫模型。
- 主題和文法重點會依日期輪替。19 個主題和 17 個文法重點互相組合，要 323 天才會重複。
- 難度為 JLPT N5～N3，長度為 10～28 個字元，內容會避開人名、品牌、政治、宗教、災難等話題。
- 同時產生简体中文、繁體中文、English 和 한국어 四種譯文。
- 產生後會驗證格式，並確認斷詞結果能拼回原句。不合格時會換一句重試。

### 備用句

在以下情況下，首頁會改為顯示內建的備用句：

- 伺服器沒有設定 `DEEPSEEK_API_KEY` 或 `GEMINI_API_KEY`。
- 產生失敗，或伺服器端無法連線到模型服務商。
- 請求逾時。

備用句共有 7 句，已預先完成斷詞和注音，依日期輪替，不會呼叫 AI。

<Note>
  今日一句只使用伺服器設定的 Key 產生，不會使用訪客在**設定**中填入的 Key。伺服器端會優先使用 DeepSeek，沒有 DeepSeek Key 時才改用 Gemini。
</Note>

<Tip>
  如果首頁一直只在幾句固定的句子中輪替，表示伺服器沒有可用的 Key，或對外網路無法連線到模型服務商。詳見[常見問題](/zh-Hant/troubleshooting)。
</Tip>

## 最近

每次成功解析後，應用程式會把原文儲存到**最近**清單。

- 紀錄只儲存在目前瀏覽器的本機儲存空間中，不會上傳到伺服器。
- 最多儲存 50 筆。相同的原文只保留最新的一次。
- 首頁預設顯示最近 3 筆。點選**顯示全部 N 筆**即可查看所有紀錄。
- 點選**清空歷史紀錄**可以刪除所有紀錄。

<Warning>
  在無痕模式或停用了本機儲存空間的瀏覽器中，頁面會提示「歷史紀錄暫時無法儲存至瀏覽器，重新整理後可能遺失。」
</Warning>
