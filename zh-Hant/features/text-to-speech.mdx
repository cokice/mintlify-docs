你可以讓應用程式朗讀輸入框中的日語原文，或在單字詳情中朗讀單一詞語的發音。

## 朗讀原文

點選輸入區的**朗讀**按鈕。滑鼠游標停留在按鈕上時，會顯示預計耗時，例如「朗讀文字（約 5–10 秒）」。

| 原文長度 | 預計耗時 |
| --- | --- |
| 20 字以內 | 5–10 秒 |
| 21–50 字 | 10–20 秒 |
| 51–100 字 | 20–30 秒 |
| 超過 100 字 | 30–60 秒 |

在單字詳細資訊面板中，點選**播放發音**可以只朗讀所選的詞。

## 選擇語音引擎

開啟輸入區的**語音設定**，在**語音引擎**中選擇：

<Tabs>
  <Tab title="Edge TTS（預設）">
    不需要任何 API Key，開箱即用。

    | 設定 | 選項 |
    | --- | --- |
    | 聲音類型 | **女聲 (Nanami)**：`ja-JP-NanamiNeural`<br />**男聲**：`ja-JP-KeitaNeural` |
    | 語速 | 從 -100 到 +100，間隔 10。介面會依數值顯示為很慢、慢、正常、快、很快。 |
  </Tab>
  <Tab title="Gemini TTS">
    使用 `gemini-3.1-flash-tts-preview` 模型，需要 Gemini API Key。只要伺服器設定了 `GEMINI_API_KEY`，或你在**設定**中填入了 Gemini Key，就能使用。

    | 聲音 | 風格 |
    | --- | --- |
    | Kore | 堅定 |
    | Puck | 開朗 |
    | Zephyr | 明亮 |
    | Aoede | 輕鬆 |
    | Leda | 年輕 |
    | Charon | 知性 |

    **朗讀風格**可選擇：

    - **自然朗讀**：預設風格。
    - **慢速朗讀**：放慢語速，適合跟讀。
    - **清晰朗讀**：發音更清楚。
  </Tab>
</Tabs>

你選擇的語音引擎、聲音、語速和風格會儲存在目前的瀏覽器中，下次開啟時自動還原。

## 朗讀失敗時

| 提示 | 處理方式 |
| --- | --- |
| 請先輸入文字 | 輸入框是空的。請先輸入要朗讀的日語。 |
| 未提供 API 金鑰 | 使用 Gemini TTS，但沒有可用的 Gemini Key。請填入 Key，或切換回 Edge TTS。 |
| 上游 TTS 請求逾時 | 語音服務在 60 秒內沒有回應。請縮短原文後再試一次。 |
| Edge TTS 傳回空白音訊 | 語音服務沒有傳回音訊。請稍後再試，或切換到 Gemini TTS。 |

<Note>
  Edge TTS 請求會經由應用程式伺服器轉送到專案作者提供的語音介面 `api.howen.ink`。如果你不希望原文傳送給這項服務，請改用 Gemini TTS。詳見[金鑰與隱私](/zh-Hant/privacy)。
</Note>
