应用的所有服务端配置都通过环境变量完成。本地开发使用 `.env.local`，Docker 部署使用 `.env.production`，Vercel 在项目的 **Settings** → **Environment Variables** 中配置。

## 环境变量

| 变量 | 是否必填 | 用途 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 推荐 | DeepSeek API Key。用于默认的解析、翻译、释义、图片识别、AI 助手和今日一句。 |
| `GEMINI_API_KEY` | 可选 | Gemini API Key。用于 Gemini 文本模型、图片识别和 Gemini TTS。 |
| `DEEPSEEK_API_URL` | 可选 | DeepSeek 的 OpenAI 兼容接口地址。留空时使用官方地址。 |
| `GEMINI_API_URL` | 可选 | Gemini 的 OpenAI 兼容接口地址。留空时使用官方地址。 |
| `CODE` | 可选 | 访问密码。留空时不需要密码。 |
| `NEXT_PUBLIC_UMAMI_SRC` | 可选 | Umami 统计脚本地址。 |
| `NEXT_PUBLIC_UMAMI_WEBSITE_ID` | 可选 | Umami Website ID。需要与 `NEXT_PUBLIC_UMAMI_SRC` 同时填写。 |

<Info>
  `DEEPSEEK_API_KEY` 和 `GEMINI_API_KEY` 至少填写一个。两个都不填时，访客必须在**设置**中填写自己的 Key 才能使用，首页的今日一句也会改用内置备用句。
</Info>

完整示例：

```env .env.production
# DeepSeek：默认文本服务商，也负责图片识别
DEEPSEEK_API_KEY=your_deepseek_api_key
DEEPSEEK_API_URL=https://api.deepseek.com/chat/completions

# Gemini：可选，启用 Gemini 模型和 Gemini TTS
GEMINI_API_KEY=your_gemini_api_key
GEMINI_API_URL=https://generativelanguage.googleapis.com/v1beta/openai/chat/completions

# 可选：访问密码
CODE=

# 可选：Umami 统计
NEXT_PUBLIC_UMAMI_SRC=
NEXT_PUBLIC_UMAMI_WEBSITE_ID=
```

## 模型服务商

应用通过 OpenAI 兼容的 Chat Completions 接口调用模型。

| 服务商 | 可用模型 | 官方接口地址 |
| --- | --- | --- |
| DeepSeek（默认） | `deepseek-flash` | `https://api.deepseek.com/chat/completions` |
| Gemini | `gemini-flash-latest`（默认）、`gemini-flash-lite-latest` | `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` |

服务端会根据服务商自动调整请求参数：

- **DeepSeek**：使用 `json_object` 格式返回结构化结果，并关闭思考模式。
- **Gemini**：使用严格的 JSON Schema 返回结构化结果。`gemini-flash-latest` 使用 `low` 推理档，`gemini-flash-lite-latest` 使用 `minimal` 推理档。

### 使用自定义接口地址

如果你通过代理或兼容网关访问模型服务商，可以设置 `DEEPSEEK_API_URL` 或 `GEMINI_API_URL`。地址必须是完整的 Chat Completions 端点，而不是 Base URL。

```env
DEEPSEEK_API_URL=https://your-gateway.example.com/v1/chat/completions
```

<Warning>
  接口地址只能在服务器环境变量中配置。浏览器请求中携带自定义 API URL 时，服务端会直接拒绝，以防止应用被当作任意地址的转发代理。
</Warning>

### 请求超时

| 场景 | 超时时间 |
| --- | --- |
| 等待上游接口响应 | 60 秒 |
| 流式输出中两段内容的最长间隔 | 90 秒 |
| 上游返回错误后，读取错误详情 | 15 秒 |

## 访问密码

设置 `CODE` 后，访客打开网站时需要先输入访问密码。

```env
CODE=choose-a-private-password
```

- 验证通过后，服务端写入一个 HttpOnly 会话 Cookie `ja_session`，有效期 7 天。
- 会话令牌使用 `CODE` 作为密钥进行 HMAC-SHA256 签名。修改 `CODE` 后，所有已登录的会话立即失效。
- 未通过验证时，解析、翻译、释义、图片识别、朗读、聊天和今日一句等接口都会返回 `401`。
- 生产环境中 Cookie 带有 `Secure` 标记，需要通过 HTTPS 访问。

<Note>
  `CODE` 适合简单的私有部署，用来防止陌生人消耗你的 API 额度。它不能替代完整的账户和权限系统。
</Note>

## Umami 统计

同时填写以下两个变量后，应用会加载 Umami 统计脚本：

```env
NEXT_PUBLIC_UMAMI_SRC=https://cloud.umami.is/script.js
NEXT_PUBLIC_UMAMI_WEBSITE_ID=your_umami_website_id
```

任意一个为空时，应用不加载 Umami。两个变量由服务端在运行时读取，修改后重启服务即可生效，Docker 部署无需重新构建镜像。

统计只记录功能用量，不记录任何内容。详见[密钥与隐私](/privacy#umami-统计)。
