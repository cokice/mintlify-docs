Japanese Text Analyzer (日本語文章解析) is an AI-powered web app for breaking down Japanese sentences. You type or paste Japanese text, and it labels each word with its kana reading, romaji, and part of speech. A full translation appears below. Click any word to see its meaning in that sentence, its usage, its conjugation, and an example sentence.

<Info>
  Want to try it first? Open the [live demo](https://nihongodemo.howen.ink/) and start analyzing without deploying anything.
</Info>

### Interface

- Supports 简体中文, 繁體中文, English, and 한국어. The interface, translations, and definitions switch together.
- Offers three themes: light, dark, and system. Works on desktop and mobile.
- Splits long texts into chunks automatically. When you paste from a web page or Markdown, formatting and links are removed automatically.

## Models

| Purpose | Default | Options |
| --- | --- | --- |
| Analysis, translation, definitions, AI assistant | DeepSeek `deepseek-flash` | Gemini `gemini-flash-latest` / `gemini-flash-lite-latest` |
| Image recognition | Same as the selected text model | — |
| Text-to-speech | Edge TTS | Gemini TTS (requires a Gemini API key) |

The API key configured on the server is shared by all visitors. Users can also enter their own key in **Settings**. That key stays in their own browser, and the app server forwards it to the model provider with each request. For details, see [Keys and privacy](/en/privacy).
