本指南将带你从源码启动应用。完成后，你可以在浏览器中输入日语句子并查看解析结果。

## 准备工作

开始前，请准备：

- Node.js 和 npm
- 一个 DeepSeek API Key，或一个 Gemini API Key
- Git

<Tip>
  如果你只想先体验文本解析，建议配置 DeepSeek。图片识别和 Gemini TTS 需要 Gemini API Key。
</Tip>

## 启动应用

<Steps>
  <Step title="克隆仓库">
    ```bash
    git clone https://github.com/cokice/japanese-analyzer.git
    cd japanese-analyzer
    ```
  </Step>

  <Step title="安装依赖">
    ```bash
    npm install
    ```
  </Step>

  <Step title="创建环境变量文件">
    <CodeGroup>
      ```powershell Windows PowerShell
      Copy-Item .env.example .env.local
      ```

      ```bash macOS / Linux
      cp .env.example .env.local
      ```
    </CodeGroup>
  </Step>

  <Step title="配置模型">
    打开 `.env.local`。至少填写一个模型服务商的 API Key。

    ```env
    DEEPSEEK_API_KEY=your_deepseek_api_key
    DEEPSEEK_API_URL=https://api.deepseek.com/chat/completions

    GEMINI_API_KEY=your_gemini_api_key
    GEMINI_API_URL=https://generativelanguage.googleapis.com/v1beta/openai/chat/completions

    CODE=
    NEXT_PUBLIC_UMAMI_SRC=
    NEXT_PUBLIC_UMAMI_WEBSITE_ID=
    ```
  </Step>

  <Step title="启动开发服务器">
    ```bash
    npm run dev
    ```

    打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。
  </Step>
</Steps>

<Check>
  页面打开后，输入一句日语并点击解析。如果使用 DeepSeek，图片上传功能会自动关闭。
</Check>
