本指南带你从源码启动应用。完成后，你可以在浏览器中输入日语句子并查看解析结果。

## 准备工作

开始前，请准备：

- [Node.js 22](https://nodejs.org/) 和 npm
- Git
- 一个 DeepSeek API Key 或 Gemini API Key

<Tip>
  推荐先配置 DeepSeek。它是默认的服务商，负责解析、翻译、释义和图片识别。只有 Gemini TTS 朗读必须使用 Gemini API Key。
</Tip>

## 启动应用

<Steps>
  <Step title="克隆仓库">
    ```bash
    git clone https://github.com/cokice/japanese-analyzer.git
    cd japanese-analyzer
    ```
  </Step>

  <Step title="安装依赖">
    ```bash
    npm ci
    ```
  </Step>

  <Step title="创建环境变量文件">
    <CodeGroup>
      ```bash macOS / Linux
      cp .env.example .env.local
      ```

      ```powershell Windows PowerShell
      Copy-Item .env.example .env.local
      ```
    </CodeGroup>
  </Step>

  <Step title="填写 API Key">
    打开 `.env.local`，至少填写一个 Key：

    ```env .env.local
    DEEPSEEK_API_KEY=your_deepseek_api_key
    ```

    其他变量都是可选的。完整列表见[配置](/configuration)。
  </Step>

  <Step title="启动开发服务器">
    ```bash
    npm run dev
    ```

    打开 [http://localhost:3000](http://localhost:3000)。
  </Step>
</Steps>

<Check>
  输入一句日语，例如「天気がいいから、散歩しましょう」，然后点击**解析**。如果看到逐词注音和中文译文，说明配置成功。首页的**今日一句**也可以直接点击解析。
</Check>

## 在手机上访问

如果你想用同一局域网里的手机访问开发服务器，让服务器监听所有网卡：

```bash
npm run dev -- --hostname 0.0.0.0
```

然后在手机浏览器中打开 `http://电脑IP:3000`。

## 只配置了 Gemini Key

应用默认使用 DeepSeek。如果你只填写了 `GEMINI_API_KEY`，打开页面后点击右上角的**设置**，把**模型服务**切换为 **Gemini**，再点击**保存设置**。

## 运行生产构建

想在本机试用生产版本时，运行：

```bash
npm run build
npm start
```

`npm start` 默认监听 `3000` 端口。
