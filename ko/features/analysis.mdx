문장 분석은 앱의 핵심 기능입니다. 일본어를 입력하면 앱이 문장을 단어 단위로 나누고, 각 단어에 가나 읽기, 로마자, 품사를 표시한 뒤 아래에 문장 전체 번역을 생성합니다.

## 일본어 문장 분석하기

<Steps>
  <Step title="원문 입력">
    입력란에 일본어를 입력하거나 붙여넣으세요. 홈 화면의 **오늘의 문장**이나 **최근** 기록을 눌러 원문을 바로 채울 수도 있습니다.
  </Step>
  <Step title="분석 누르기">
    **분석**을 누르세요. 스트리밍 출력이 켜져 있으면 단어가 생성되는 대로 표시됩니다.
  </Step>
  <Step title="결과 읽기">
    결과 영역에 단어별 후리가나가 표시됩니다. 번역 영역은 분석이 끝나면 원문 전체를 자동으로 번역합니다.
  </Step>
</Steps>

분석 중에는 **분석 중지**를 눌러 현재 요청을 멈출 수 있습니다. 분석이 끝나면 **원문 편집**을 눌러 문장을 수정하거나, **새 문장**을 눌러 입력을 비우고 다시 시작하세요.

## 분석 결과에 포함되는 내용

각 단어에는 세 가지 정보가 있습니다.

| 정보 | 설명 |
| --- | --- |
| 후리가나 | 한자가 포함된 단어 위에 표시합니다. 가나로만 된 단어에는 읽기를 중복 표시하지 않습니다. |
| 로마자 | 가나를 로컬에서 변환하며 헵번식 표기를 사용합니다. 장음은 모음 표기를 그대로 둡니다(예: `ou`). |
| 품사 | 각 단어 아래에 색상 밑줄이 있으며, 색상은 품사 그룹을 나타냅니다. |

결과 아래의 범례에는 이 문장에 나온 품사 그룹이 표시됩니다: 명사, 동사, 형용사, 형용동사, 부사, 연체사, 접속사, 감동사, 조사, 조동사, 기타. 문장 부호에는 밑줄을 표시하지 않습니다.

### 읽기 표시 켜기/끄기

결과 영역 위쪽에 두 개의 스위치가 있습니다.

- **후리가나 표시**: 한자 위의 후리가나를 켜거나 끕니다.
- **로마자 표시**: 단어 아래의 로마자를 켜거나 끕니다.

읽기 표시를 끄고 원문만으로 읽기 연습을 한 뒤, 언제든 다시 켜서 확인할 수 있습니다.

## 문장 전체 번역

분석이 끝나면 앱이 원문 전체를 현재 화면 언어로 자동 번역합니다. 번역 영역에서는 다음 작업을 할 수 있습니다.

- **복사**: 번역을 복사합니다.
- **다시 번역**: 같은 원문의 번역을 다시 생성합니다.
- **접기** / **펼치기**: 번역 영역을 접거나 펼칩니다.

<Note>
  번역 언어는 화면 언어를 따릅니다. English로 바꾸면 번역, 단어 뜻풀이, AI 도우미의 답변이 모두 영어로 바뀝니다. 자세한 내용은 [설정](/ko/features/settings#화면-언어)을 참고하세요.
</Note>

## 긴 글 나누어 분석

긴 단락은 자동으로 여러 구간으로 나뉩니다. 각 구간은 약 280자이며 최대 420자를 넘지 않습니다. 앱은 마침표, 물음표, 느낌표 같은 문장 끝에서 나누고, 짝을 이루는 괄호와 따옴표는 나누지 않습니다.

- 스트리밍 출력이 켜져 있으면 최대 3개 구간을 동시에 요청하고, 꺼져 있으면 구간을 하나씩 차례로 분석합니다. 결과는 모두 원문 순서대로 이어 붙입니다.
- 어떤 구간이 완전한 결과를 반환하지 않으면 오류 메시지에 몇 번째 구간인지 표시됩니다. 예: 「2/5번째 구간의 분석 결과가 불완전합니다. 다시 시도해 주세요.」
- 앱은 각 구간의 단어를 이어 붙여 원문과 일치하는지 검사하고, 일치하지 않으면 다시 시도하라고 안내해 글자가 빠지거나 늘어나는 것을 막습니다.

## 웹 페이지와 Markdown 붙여넣기

웹 페이지나 Markdown 문서에서 텍스트를 복사해 붙여넣으면 앱이 서식을 자동으로 정리합니다.

- HTML 태그, 스크립트, 스타일, 숨겨진 요소를 제거하고 단락과 줄바꿈은 유지합니다.
- Markdown 기호를 제거하고 이미지의 대체 텍스트는 유지합니다.
- 링크 주소를 제거하고 링크 텍스트만 남깁니다.

<Tip>
  `https://` 링크가 포함된 텍스트를 직접 입력하면 앱은 링크를 하나의 기호로 통째로 보존하므로, 모델이 링크를 나누거나 읽기를 붙이지 않습니다.
</Tip>

## 스트리밍 출력

**스트리밍 출력**은 기본으로 켜져 있어 분석, 번역, 뜻풀이가 실시간으로 표시됩니다. 네트워크가 불안정해 결과가 자주 끊긴다면 **설정**에서 끄고 전체 결과를 한 번에 받도록 바꿀 수 있습니다.

## 분석에 실패했을 때

| 메시지 | 원인과 해결 방법 |
| --- | --- |
| API 키가 없습니다 | 서버와 브라우저 모두에 사용 가능한 키가 없습니다. **설정**에서 키를 입력하거나 관리자에게 서버 키 설정을 요청하세요. |
| 모델이 출력을 잘랐습니다(`finish_reason: length`) | 출력이 너무 깁니다. 원문을 줄인 뒤 다시 분석하세요. |
| 모델의 콘텐츠 필터가 출력을 중단했습니다 | 모델 제공업체가 해당 내용을 거부했습니다. |
| 분석 결과가 원문과 일치하지 않습니다 | 모델이 반환한 단어가 원문과 일치하지 않습니다. 다시 분석하세요. |
| 상위 API 요청 시간이 초과되었습니다. 잠시 후 다시 시도해 주세요. | 모델 제공업체가 60초 안에 응답하지 않았습니다. 잠시 후 다시 시도하세요. |
| 상위 스트리밍 응답이 멈췄습니다. 다시 시도해 주세요. | 스트리밍 출력에서 90초 동안 새 내용이 없었습니다. 다시 시도하거나 **설정**에서 **스트리밍 출력**을 끄세요. |

<Note>
  오류 메시지는 현재 화면 언어로 표시됩니다. 모델 제공업체가 반환한 원본 오류 메시지(예: `HTTP 429: upstream quota exceeded`)는 문제 해결을 돕기 위해 원문 그대로 표시됩니다.
</Note>

더 많은 문제는 [자주 묻는 질문](/ko/troubleshooting)을 참고하세요.
