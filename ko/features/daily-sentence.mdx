홈 화면에는 빠르게 시작하도록 돕는 두 영역, **오늘의 문장**과 **최근**이 있습니다. 둘 중 아무 항목이나 누르면 앱이 원문을 바로 채우고 분석을 시작합니다.

## 오늘의 문장

오늘의 문장은 매일 추천하는 짧은 일본어 문장으로, 후리가나와 현재 화면 언어의 번역이 함께 표시됩니다. 누르면 바로 이 문장을 분석합니다.

### 문장 생성 방식

- 문장은 **일본 시간** 자정에 바뀌며, 하루 동안 모든 방문자가 같은 문장을 봅니다.
- 서버가 하루에 한 번 AI로 생성하고 결과를 캐시합니다. 같은 날의 이후 요청에서는 모델을 다시 호출하지 않습니다.
- 주제와 문법 항목은 날짜에 따라 순환합니다. 주제 19개와 문법 항목 17개를 조합하므로 323일이 지나야 반복됩니다.
- 난이도는 JLPT N5~N3, 길이는 10~28자이며, 인명, 브랜드, 정치, 종교, 재난 같은 주제는 피합니다.
- 简体中文, 繁體中文, English, 한국어의 네 가지 번역을 함께 생성합니다.
- 생성한 뒤 형식을 검사하고, 단어를 이어 붙였을 때 원래 문장과 일치하는지 확인합니다. 기준에 맞지 않으면 다른 문장으로 다시 시도합니다.

### 예비 문장

다음과 같은 경우 홈 화면에는 내장된 예비 문장이 표시됩니다.

- 서버에 `DEEPSEEK_API_KEY` 또는 `GEMINI_API_KEY`가 설정되어 있지 않은 경우.
- 생성에 실패했거나 서버가 모델 제공업체에 접속할 수 없는 경우.
- 요청 시간이 초과된 경우.

예비 문장은 모두 7개이며, 단어 분리와 후리가나가 미리 되어 있고, 날짜에 따라 순환하며 AI를 호출하지 않습니다.

<Note>
  오늘의 문장은 서버에 설정된 키로만 생성하며, 방문자가 **설정**에서 입력한 키는 사용하지 않습니다. 서버는 DeepSeek를 우선 사용하고, DeepSeek 키가 없으면 Gemini를 사용합니다.
</Note>

<Tip>
  홈 화면이 계속 몇 개의 고정된 문장만 반복한다면 서버에 사용 가능한 키가 없거나, 외부 네트워크에서 모델 제공업체에 접속할 수 없는 것입니다. 자세한 내용은 [자주 묻는 질문](/ko/troubleshooting)을 참고하세요.
</Tip>

## 최근

분석에 성공할 때마다 앱은 원문을 **최근** 목록에 저장합니다.

- 기록은 현재 브라우저의 로컬 저장소에만 저장되며 서버에 업로드되지 않습니다.
- 최대 50개까지 저장합니다. 같은 원문은 가장 최근 것 하나만 남깁니다.
- 홈 화면에는 기본적으로 최근 3개가 표시됩니다. **전체 N개 보기**를 누르면 모든 기록을 볼 수 있습니다.
- **기록 지우기**를 누르면 모든 기록이 삭제됩니다.

<Warning>
  시크릿 모드이거나 로컬 저장소가 비활성화된 브라우저에서는 「현재 브라우저에 기록을 저장할 수 없어 새로고침하면 사라질 수 있습니다.」라는 안내가 표시됩니다.
</Warning>
