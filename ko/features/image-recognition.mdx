이미지 인식은 스크린샷, 사진, 만화에서 일본어 글자를 추출해 입력란에 채워 줍니다. 글자가 맞는지 확인한 뒤 **분석**을 누르세요.

## 이미지에서 글자 추출하기

<Tabs>
  <Tab title="이미지 업로드">
    1. 입력란 옆의 **이미지에서 글자 추출** 버튼을 누릅니다.
    2. 이미지 파일을 하나 선택합니다.
    3. 인식이 끝날 때까지 기다리면 추출한 글자가 입력란에 채워집니다.
  </Tab>
  <Tab title="스크린샷 붙여넣기">
    1. 스크린샷을 찍거나 이미지를 복사합니다.
    2. 입력란에서 <kbd>Ctrl</kbd> + <kbd>V</kbd>(macOS에서는 <kbd>⌘</kbd> + <kbd>V</kbd>)를 누릅니다.
    3. 앱이 이미지를 감지하면 자동으로 인식을 시작합니다.
  </Tab>
</Tabs>

앱은 글자 추출만 하며 이미지 내용을 번역하거나 해석하지 않습니다. 이미지 속 줄바꿈은 공백으로 바뀌며 원문 순서는 그대로 유지됩니다.

인식이 끝나면 「글자를 추출했습니다. 내용을 확인한 후 ‘분석’을 눌러 주세요.」라는 안내가 표시됩니다. 인식 결과를 확인하고 수정한 다음 **분석**을 누르세요.

<Tip>
  스트리밍 출력이 켜져 있으면 인식한 글자가 입력란에 차례로 표시됩니다.
</Tip>

## 사용하는 모델

이미지 인식은 **설정**에서 선택한 텍스트 모델을 사용합니다.

| AI 제공업체 | 인식 모델 |
| --- | --- |
| DeepSeek | `deepseek-flash` |
| Gemini | 선택한 모델 버전과 동일. `gemini-flash-latest` 또는 `gemini-flash-lite-latest` |

## 이미지 처리와 제한

- 업로드하기 전에 앱이 브라우저에서 이미지를 압축합니다. 긴 변이 1600픽셀을 넘으면 비율을 유지하며 줄이고, 70% 품질로 다시 인코딩합니다.
- 압축된 이미지 데이터는 8 MB를 넘을 수 없습니다.
- 이미지 파일만 받습니다. 다른 형식의 파일을 선택하면 「이미지 파일을 업로드해 주세요.」라는 안내가 표시됩니다.

## 인식에 실패했을 때

| 메시지 | 해결 방법 |
| --- | --- |
| 이미지에서 글자를 찾지 못했습니다 | 이미지에 인식할 수 있는 글자가 없거나 글자가 너무 작습니다. 더 선명한 이미지로 바꾸세요. |
| 이미지를 불러올 수 없습니다 / 파일을 읽을 수 없습니다 | 이미지 파일이 손상되었거나 브라우저가 지원하지 않는 형식입니다. PNG나 JPEG를 사용하세요. |
| API 키가 없습니다 | 현재 제공업체에 사용 가능한 키가 없습니다. **설정**에서 입력하거나 관리자에게 문의하세요. |

<Note>
  이미지는 인식할 때만 앱 서버를 거쳐 모델 제공업체로 전송되며, 앱은 이미지를 저장하지 않습니다. Umami 통계도 이미지나 추출 결과를 기록하지 않습니다. 자세한 내용은 [API 키와 개인정보](/ko/privacy)를 참고하세요.
</Note>
