분석이 끝나면 결과의 모든 단어를 누를 수 있습니다. 앱은 문장 전체의 맥락을 바탕으로 사전식 뜻풀이를 생성하며, 모든 뜻을 나열하지 않고 이 단어가 이 문장에서 쓰인 뜻만 설명합니다.

## 단어 상세 설명 보기

분석 결과에서 밑줄 친 단어를 누르면 상세 패널에 다음 내용이 표시됩니다.

| 항목 | 설명 |
| --- | --- |
| 읽기와 로마자 | 선택한 단어의 가나 읽기와 로마자. 모델이 원래 읽기의 오류를 발견하면 바로잡습니다. |
| 뜻 | 이 문장에서 쓰인 뜻의 간결한 뜻풀이. 보통 한두 개의 비슷한 표현으로 제시합니다. |
| 기본형 | 단어의 사전형. 예를 들어 「読んだ」의 기본형은 「読む」입니다. |
| 품사 | 학교 문법 기준 품사이며, 필요하면 세부 분류를 붙입니다. 예: 「動詞（五段・他動）」. |
| 이 문장에서의 용법 | 이 단어와 앞뒤 단어의 결합, 그리고 이 문장에서 하는 구체적인 역할. |
| 활용형 | 이 문장에서 실제로 활용된 경우에만 표시합니다. 예: 「読む → 読んだ; た형, 과거를 나타냄.」 |
| 예문 | 같은 뜻 또는 같은 활용형을 사용한 짧은 예문 하나와 번역. |

패널의 다른 기능:

- **발음 듣기**: 선택한 단어를 읽어 줍니다.
- **뜻 다시 조회**: 같은 단어의 뜻풀이를 다시 생성합니다.
- **전체 보기** / **접기**: 긴 설명을 펼치거나 접습니다.

<Note>
  뜻풀이는 현재 화면 언어로 출력됩니다. 원문이 1000자를 넘으면 요청 길이를 줄이기 위해 선택한 단어의 앞뒤 두 문장씩만 문맥으로 보냅니다.
</Note>

## 여러 단어 선택

문형 「〜なければならない」나 관용 표현처럼, 몇 개의 단어를 함께 봐야 뜻이 분명해지는 경우가 있습니다. 연속된 여러 단어를 선택하면 앱이 이를 하나로 묶어 설명합니다.

<Tabs>
  <Tab title="데스크톱">
    - 마우스를 누른 채 여러 단어 위로 드래그하세요.
    - 또는 단어 하나를 누른 다음 <kbd>Shift</kbd>를 누른 채 다른 단어를 누르면 그 사이의 모든 단어가 선택됩니다.
  </Tab>
  <Tab title="휴대폰">
    1. 단어 하나를 약 0.5초 길게 눌러 선택을 시작합니다.
    2. 다른 단어를 누르면 그 구간이 선택됩니다.
  </Tab>
  <Tab title="상세 패널에서">
    1. 단어 하나를 눌러 상세 패널을 엽니다.
    2. **여러 단어 함께 선택**을 누릅니다.
    3. 다른 단어를 누르면 그 구간이 선택됩니다.
  </Tab>
</Tabs>

### 선택 결과

앱은 먼저 선택한 구간이 어떤 유형인지 판단한 뒤 그에 맞는 설명을 제공합니다.

| 유형 | 의미 | 예시 |
| --- | --- | --- |
| 한 단어 | 원래 하나의 단어인데 나뉘어 있던 경우. 예: 복합어, 고유 명사. | 図書館 |
| 문법 형식 | 고정된 문형. 「〜」는 접속 위치를 나타냅니다. | 〜なければならない |
| 관용 표현 | 관용구 또는 굳어진 표현. | 気がする |
| 어구 | 일반적인 단어 결합이거나 단순히 여러 단어가 이어진 경우. | 本を読む |

뜻풀이와 예문 외에, 선택 결과에는 **구성**도 표시되어 이 구간이 어떤 부분으로 이루어져 있고 각 부분이 어떤 역할을 하는지 설명합니다. 예:

```text
なけれ（ない의 가정형）＋ば（조건）＋なら（なる의 부정 접속）＋ない: 그렇게 하지 않으면 안 된다, 즉 "해야 한다".
```

### 나뉜 단어 합치기

앱이 선택한 내용을 **한 단어**로 판단하면 상세 패널에 「사실 하나의 단어입니다」라는 안내와 함께 **한 단어로 합치기** 버튼이 표시됩니다. 버튼을 누르면 현재 분석 결과에서 해당 단어들이 하나로 합쳐지고 읽기도 함께 업데이트됩니다.

<Tip>
  합치기는 현재 페이지의 분석 결과에만 적용됩니다. 같은 원문을 다시 분석하면 모델이 단어를 새로 나눕니다.
</Tip>
