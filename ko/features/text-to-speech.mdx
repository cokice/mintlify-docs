입력란의 일본어 원문을 앱이 읽어 주게 하거나, 단어 상세 패널에서 단어 하나의 발음을 들을 수 있습니다.

## 원문 듣기

입력 영역의 **듣기** 버튼을 누르세요. 마우스를 올리면 버튼에 예상 소요 시간이 표시됩니다. 예: 「소리 내어 읽기 (약 5~10초)」

| 원문 길이 | 예상 소요 시간 |
| --- | --- |
| 20자 이하 | 5–10초 |
| 21–50자 | 10–20초 |
| 51–100자 | 20–30초 |
| 100자 초과 | 30–60초 |

단어 상세 패널에서 **발음 듣기**를 누르면 선택한 단어만 읽어 줍니다.

## 음성 엔진 선택

입력 영역의 **음성 설정**을 열고 **음성 엔진**에서 선택하세요.

<Tabs>
  <Tab title="Edge TTS(기본값)">
    API 키 없이 바로 사용할 수 있습니다.

    | 설정 | 옵션 |
    | --- | --- |
    | 음성 유형 | **여성 (Nanami)**: `ja-JP-NanamiNeural`<br />**남성**: `ja-JP-KeitaNeural` |
    | 읽기 속도 | -100부터 +100까지 10 단위. 화면에는 값에 따라 매우 느리게, 느리게, 보통, 빠르게, 매우 빠르게로 표시됩니다. |
  </Tab>
  <Tab title="Gemini TTS">
    `gemini-3.1-flash-tts-preview` 모델을 사용하며 Gemini API 키가 필요합니다. 서버에 `GEMINI_API_KEY`가 설정되어 있거나 **설정**에서 Gemini 키를 입력했다면 사용할 수 있습니다.

    | 음성 | 스타일 |
    | --- | --- |
    | Kore | 단호한 |
    | Puck | 경쾌한 |
    | Zephyr | 밝은 |
    | Aoede | 편안한 |
    | Leda | 젊은 |
    | Charon | 차분한 설명 |

    **읽기 스타일**에서 고를 수 있는 항목:

    - **자연스럽게**: 기본 스타일입니다.
    - **천천히**: 읽기 속도를 늦춰 따라 읽기에 좋습니다.
    - **또렷하게**: 발음을 더 분명하게 합니다.
  </Tab>
</Tabs>

선택한 음성 엔진, 목소리, 읽기 속도, 스타일은 현재 브라우저에 저장되어 다음에 열 때 자동으로 복원됩니다.

## 읽기에 실패했을 때

| 메시지 | 해결 방법 |
| --- | --- |
| 먼저 문장을 입력해 주세요 | 입력란이 비어 있습니다. 읽을 일본어를 먼저 입력하세요. |
| API 키가 없습니다 | Gemini TTS를 사용 중인데 사용 가능한 Gemini 키가 없습니다. 키를 입력하거나 Edge TTS로 되돌리세요. |
| 상위 TTS 요청 시간이 초과되었습니다. 잠시 후 다시 시도해 주세요. | 음성 서비스가 60초 안에 응답하지 않았습니다. 원문을 줄인 뒤 다시 시도하세요. |
| Edge TTS 요청 실패 (HTTP 상태 코드) | Edge TTS 음성 API가 오류를 반환했습니다. 잠시 후 다시 시도하거나 Gemini TTS로 바꾸세요. |
| Edge TTS가 빈 오디오를 반환했습니다 | 음성 서비스가 오디오를 반환하지 않았습니다. 잠시 후 다시 시도하거나 Gemini TTS로 바꾸세요. |

<Note>
  Edge TTS 요청은 앱 서버를 거쳐 프로젝트 제작자가 제공하는 음성 API `api.howen.ink`로 전달됩니다. 원문이 이 서비스로 전송되는 것을 원하지 않는다면 Gemini TTS를 사용하세요. 자세한 내용은 [API 키와 개인정보](/ko/privacy)를 참고하세요.
</Note>
