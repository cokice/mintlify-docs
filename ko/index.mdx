일본어 문장 분석(日本語文章解析)은 AI 기반 일본어 문장 분석 웹 앱입니다. 일본어 문장을 입력하거나 붙여넣으면 단어마다 가나 읽기, 로마자, 품사를 표시하고 아래에 문장 전체 번역을 보여 줍니다. 아무 단어나 누르면 이 문장에서의 뜻, 용법, 활용과 예문을 볼 수 있습니다.

<Info>
  먼저 체험해 보고 싶다면 [온라인 데모](https://nihongodemo.howen.ink/)를 여세요. 배포하지 않고 바로 분석을 시작할 수 있습니다.
</Info>

### 화면

- 简体中文, 繁體中文, English, 한국어를 지원합니다. 화면, 번역, 뜻풀이가 함께 바뀝니다.
- 라이트, 다크, 시스템 설정 따르기의 세 가지 테마를 지원합니다. 데스크톱과 휴대폰에서 모두 사용할 수 있습니다.
- 긴 글은 자동으로 나누어 분석합니다. 웹 페이지나 Markdown을 붙여넣으면 서식과 링크를 자동으로 제거합니다.

## 모델

| 용도 | 기본값 | 선택 가능 |
| --- | --- | --- |
| 분석, 번역, 뜻풀이, AI 도우미 | DeepSeek `deepseek-flash` | Gemini `gemini-flash-latest` / `gemini-flash-lite-latest` |
| 이미지 인식 | 선택한 텍스트 모델과 동일 | — |
| 음성 읽기 | Edge TTS | Gemini TTS(Gemini API 키 필요) |

서버에 설정한 API 키는 모든 방문자가 함께 사용합니다. 사용자는 **설정**에서 자신의 키를 입력할 수도 있습니다. 이 키는 사용자의 브라우저에 저장되며, 요청 시 앱 서버를 거쳐 모델 제공업체로 전달됩니다. 자세한 내용은 [API 키와 개인정보](/ko/privacy)를 참고하세요.

## 기술 스택

- Tailwind CSS
- OpenAI 호환 API로 DeepSeek와 Gemini 호출
