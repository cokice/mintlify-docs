# 日本語文章解析文档

这是 [japanese-analyzer](https://github.com/cokice/japanese-analyzer) 的 Mintlify 文档站源码。

文档包括：

- 产品功能与模型说明
- 本地快速开始
- 环境变量与隐私配置
- Vercel、Docker Compose 和 Docker 部署
- 开发命令、项目结构与镜像发布

## 本地预览

安装 Mintlify CLI：

```bash
npm i -g mint
```

在仓库根目录启动预览：

```bash
mint dev
```

然后打开 `http://localhost:3000`。

## 验证

```bash
mint validate
mint broken-links
```
